# Switch path review

I traced both switch payloads from the referencing instructions in the Smali and compared each path with the recovered classes. The key -3 route computes a negation on a disposable local and throws the first argument once. The key 17 route complements the same disposable local and throws the second argument once. Those arithmetic results have no subsequent use. The default jump bypasses both arms and returns zero. Another constant and jump inside the listing has no incoming route. Each Java explanation assumes successful resolution of the shared string before the switch.

For dispatch, the old throw at 8 consults the IllegalArgumentException clause at handler 14 before the catch-all at 17. The corresponding new throw at 12 escapes. Conversely, the old throw at 12 escapes and the corresponding new throw at 8 consults that ordered chain. A typed failure returns -3 on its protected route. An ArithmeticException or a NullPointerException from throwing null returns -5 there. Neither handler replaces an exception on the unprotected route. The recovered dispatch methods show exactly one try inside the switch, in the first old arm and the second new arm.

For preserved, both throw instructions remain covered after their blocks exchange physical positions. The recovered switch is enclosed in the same ordered catches on both sides. Each active throw, the selected argument, the successful default and the two handler results agree path by path. Its unchanged result distinguishes physical order from which operations actually receive each handler.

The candidate diff reports old 8 to new 12 and old 12 to new 8 with their respective coverage. The CLI regression checked both site pairs, the handler ordering and the unchanged control. For each version, eighteen combinations of method, key and exception input were executed against the authored Java and recovered Java separately on OpenJDK 21.0.12.1. The checks observed the return value or escaping exception type and identity. ART and VM resource failures were not exercised.
