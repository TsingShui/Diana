# Bound value folding review

The Smali writes zero to the same register that initially holds an integer argument. The write and the incoming method argument are distinct reaching definitions. The statement list alone contains only the write. Treating the conditional assignment as the source variable's only possible value caused the previous output to pass zero to a helper even on a path that had just tested the value as nonzero.

In `guarded(7, false)`, the Smali branches around the write, skips the early return and casts 7 to float. The first helper receives two copies of 7.0. In the recovered Java, the reset guard updates the parameter, the zero check returns minus one, and the cast reads that same parameter on the surviving path. A false helper result adds one call carrying the same argument twice. A true result bypasses it. Either call can throw before the final return.

In `pair`, both reset guards apply before the zero test. Clearing only the first argument therefore produces the ordered pair zero and the second input. Clearing only the second produces the reverse arrangement. Clearing both takes the early return. Keeping both preserves their independent float conversions. The calls are ordered as `take`, then conditionally `done` and `keep`. Both successful paths after `take` return the selected integer sum, including signed overflow. A helper exception prevents subsequent calls and the return.

The catch path in `caughtDefault` takes its object from the throwing instruction. Clearing it makes the type test false. Retaining an `IllegalStateException` makes it true, while retaining a plain `RuntimeException` makes it false. The recovered handler passes that selected object to each `replacement`, computes the integer type-test result once, and passes it with 5 to the optional and final `keep` calls. The final `replacement` precedes the result. Normal completion returns minus one. An unrelated error from `mayThrow` escapes, as do helper exceptions from the handler.

In `localConstant`, the only reaching definition comes from the literal 37. The ordinary output passes 37.0f twice at each of the two call sites and retains the guard around the first site.

A local JVM replay compared the recovered Java with the authored Java explanation using the same observable helper implementations. Its 2,736 scenarios covered both helper return values, exceptions at each of the first five call positions, both reset switches, signed integer limits and the first integer above the 24-bit float precision boundary. Catch inputs included normal completion, two runtime exception classes and an escaping error. Comparisons used the ordered call trace, raw float bits and the returned value or thrown class. The previous constant-folding implementation differed in 1,656 scenarios. The corrected output matched all 2,736 scenarios. This replay executed Java callers and test doubles. The path review above establishes correspondence to the assembled Smali.
